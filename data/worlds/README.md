# 世界目录

`catalog.json` 是内置世界公开元数据的唯一权威来源。新增或修改世界时，只在这里维护：

- 名称、分类、颜色和角色卡技能名称；
- 日常快捷动作；
- 预设名称与说明；
- 世界选择卡片的图标、简介和标签。

私有叙事资产位于 `backend/app/domain/world_content.py`，包含 prompt、世界风味和命名约束，不会由 `/api/worlds` 或静态目录下发。新增世界还必须补齐角色状态模板和相关领域映射；测试会检查目录、私有资产、预设和状态模板是否完整。

不要重新在 `index.html` 或后端 Python 对象里复制上述公开元数据。前端从本目录加载，后端 `app.domain.worlds` 也读取同一文件。
