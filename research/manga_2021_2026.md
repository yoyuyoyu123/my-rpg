# 日本漫画／改编漫画标签研究：2021—2026YTD

## 1. 数据集概况

本批次收录 68 部作品，目标是补足 AI 小说游戏可用的身份、身体、职业、关系、叙事位置和故事发动机，不以销量榜代替类型研究。

| 年份 | 收录数 | 漫画原创 | 小说／游戏改编 | 实录／非虚构 |
|---|---:|---:|---:|---:|
| 2021 | 10 | 8 | 2 | 0 |
| 2022 | 10 | 9 | 1 | 0 |
| 2023 | 12 | 11 | 1 | 0 |
| 2024 | 12 | 12 | 0 | 0 |
| 2025 | 14 | 12 | 2 | 0 |
| 2026YTD | 10 | 8 | 1 | 1 |
| 合计 | 68 | 61 | 6 | 1 |

机器可读文件为 `manga_works_2021_2026.json`。与首批 2016—2020 保持同一核心字段，并增加 `evidence_grade`：

```text
region / year / title / author / platform_or_publisher
source_type / source_material / popularity_basis / tags
protagonist_role / narrative_features / why_included
evidence_grade / sources
```

### 年份口径

`year` 表示作品形成显著可见度的代表节点，可能对应获奖、入围、用户榜、重要单行本或商业漫画化，并非统一的初次连载年。因此本表适合观察“某种叙事何时被集中看见”，不适合直接统计年度新作数量。

### 来源与证据

- A级：官方奖项、出版社、连载平台或作品官网。本批所有记录至少有一个A级来源。
- B级：作者官方页面、行业媒体、可追溯书目，用于补充冷门作品。
- C级：百科与社区仅作发现线索，不作为唯一证据。

主干来源包括[漫画大赏历年档案](https://www.mangataisho.com/archives/)、[下一部人气漫画大赏历代榜单](https://tsugimanga.jp/)、出版社书目和官方连载页。2026YTD 以[漫画大赏2026二次入围名单](https://www.mangataisho.com/news/2026/01/2026-1.html)及截至 2026 年 7 月已公开的出版社资料为界。

## 2. 年度趋势

### 2021：类型混搭、游戏素养与“传奇之后”

- 《胆大党》把外星人、乡野怪谈、身体异变、动作和恋爱放在同一世界，说明题材标签可以并列，而非只能选一个主类型。
- 《香格里拉·开拓异境》把 VR 世界写成正常娱乐与玩家文化，主角靠规则研究和操作，不需要被困游戏或承担救世使命。讲谈社官方书目明确其为网络小说漫画化，并记录其后获讲谈社漫画奖。
- 《坂本日常》从顶尖杀手退休、结婚、发福、开店之后开始；强者、父亲、店主和旧职业人脉可同时成立。
- 《This Communication》让主角成为资源与人员管理者，黑暗冲突来自管理目标和伦理债务，不是“所有人都知道秘密但不说”。
- 《两人逃避》《星灵感应》分别以成年同居偷闲和少女火箭项目维持剧情，低压力并不等于没有行动。
- 《指尖相触，恋恋不舍》把听觉、手语和沟通方式作为互动条件，而不是悲剧标签或超能力。
- 《猫活尸之夜》把丧尸感染后果改成“变猫”，展示灾难规则可以荒诞、可爱且真正改变身体玩法。

核心变化：世界类型不再自动决定主角；玩家可以是退役者、普通玩家、项目成员、管理者、残障学生或爱猫幸存者。

### 2022：非人身体、晚年成长、固定地点与照料关系

- 《达尔文事变》让人猿混血身体进入学校、法律、媒体、动物权利与激进政治，非人设定会改变制度反应。
- 《海波追寻的终幕》以 65 岁丧偶女性重返学校学电影，年龄不是背景数字，而会影响资源、关系和自我判断。
- 《舞冰的祈愿》让失败教练与晚起步儿童成为相互押注的双主角；师徒不是单向传功。
- 《在超市后门吸烟的两人》用固定地点和重复会面写成年慢热关系，证明没有大事件也能保持张力。
- 《拉面赤猫》把猫咪社会落实到卫生、排班、服务与人类员工后勤；异种族世界可以是职业日常。
- 《想做饭的女人和想吃饭的女人》把料理、性别期待、邻里与百合关系连接，情感线拥有具体的重复行动。
- 《噗妮露是可爱史莱姆》用可变液态身体表达身份和青春期，而不是走吞噬进化与建国模板。
- 《恶役千金的真面目》反转转生者夺舍：原人格因爱护体内转生者而重新接管身体，形成双魂继承与替友复仇。
- 《异世界谢谢》让两名成年挚友无外挂穿越，类型知识不能让世界配合他们。

核心变化：身体、年龄、职业和关系开始独立组合；“非人”“异世界”“恶役千金”都不再等于单一路线。

### 2023：创作劳动、直接沟通、酷儿关系与原住民视角

- 《去画吧，然后死》《朱音落语》把漫画制作和口头表演拆成可训练、可反馈、可合作的职业主线。
- 《女校之星》依靠语气、观察和微小误会写职业喜剧，是反“无意义景物 + 强行危机”的校准样本。
- 《正相反的你与我》较早确认恋爱关系，后续靠直接沟通、边界与朋友群像发展，不用无限拖延告白。
- 《天幕下的贾度加尔》从被征服的波斯知识女性观看蒙古帝国；宫廷身份可以是俘虏、侍女、翻译、医者和知识劳动者。
- 《光死去的夏天》把人外替身与挚友丧失绑定。它有高悬疑浓度，但秘密始终服务一个明确的亲密关系核心。
- 《我在意的人不是男人》以音乐、校内外外观和性别误认开启百合，揭示后故事继续，而不是靠骗局拖长。
- 《转生成猫的大叔》把普通上班族变成宠物猫，没有升级、成人化或异世界霸业。
- 《转生王女与天才千金的魔法革命》让转生王女、被退婚千金、百合、魔道具研究与政治改革同时成立。
- 《致和平之国的岛崎》关注前战斗人员脱离组织后的咖啡店、邻里与普通生活训练。

核心变化：2023 样本强烈支持“身份例外 + 具体劳动 + 关系持续”，而不是只扩大世界威胁。

### 2024：神经多样性、普通才能、工匠轮换与关系变奏

- 《为了与你在宇宙行走》把执行困难拆成清单、预演、环境适配和求助，差异不会在成长后消失。
- 《神田极乐町职人故事》用轮换工匠和工序写江户；世界史可以由职业单元构成，不必固定一名英雄。
- 《钻石的功罪》显示压倒性天赋会伤害队伍平衡；高属性不是无条件奖励。
- 《环与周》在不同时代、性别和身份中变奏同一关系母题，为多周目关系系统提供范本。
- 《平屋小品》《普通轻音部》分别让“不追主流成功”与“没有天才数值”成为可持续主体。
- 《去家庭餐厅吧。》从经典桥段结束后继续书写关系，证明后日谈应是可选开局阶段。
- 《公司与私生活》把职业人格、私服、异性装与社交身份分层；一名角色不应只有一张固定标签卡。
- 《异世界武士》让前现代女性武士穿越到奇幻世界，打破“现代男性带知识红利”的默认。
- 《超爱暴食的望月小姐》将美食日常写成欲望喜剧与身体惊悚，说明语气必须与题材分离。

核心变化：不完美、普通、场景化身份和职业细节成为主角吸引力，而非等待外挂修复的缺陷。

### 2025：明确限制、职业系统、成年重启与女性双人事业

- 《爱丽丝，直至宇宙》把宇航员梦想落到语言、数学、教育资源和长期支援；“天赋”不自动绕过制度。
- 《COSMOS》把外星人世界写成保险理赔和事故调查，赛博／科幻职业远超黑客、佣兵、警察三种。
- 《这世间值得一战》不依赖转生，以离职、拒绝讨好和关系清算完成成年女性人生重启。
- 《死而回溯的魔法学校生活》让女主保留旧周目恋爱记忆，但前恋人好感归零；知识不等于关系所有权。
- 《图书馆的大魔法师》以司书考试、书籍修复、知识保存和多民族制度组成奇幻冒险。
- 《感谢投球》给最强投手“三球”硬限制，迫使团队配置、时机和心理战成为核心。
- 《全部都要救》把动物保护写成医疗、领养、募资、邻里和组织协作，善意不能跳过资源约束。
- 《Baby车中黑客》用车内空间改造和微旅行支撑女性双人日常。
- 《无力圣女与无能王女》让魔力为零的圣女和无法施法的王女共同救国，百合关系可承担公共事业。
- 《Love Bullet》把丘比特写成死后职业，恋爱系统本身具有规则、伦理和同僚分歧。

核心变化：一个清楚的限制或职业循环，比“潜藏惊天身世”更能稳定产生回合选择。

### 2026YTD：维护、研究、出版、店铺与非虚构观察

- 《书多到可以卖》以旧书店连接书籍去向和顾客人生，是固定地点、物品记忆与低压力单元剧的代表。
- 《邪神的便当店》让受罚邪神靠经营便当店变化，魔王／神明降格后不一定复仇或恢复巅峰。
- 《解剖怪兽》关注巨大怪兽死后的学者、样本、寄生物、灾害创伤与二次生态；怪兽世界不只有防卫队。
- 《食人公寓与房东梅森》把房东、设施管理、社区与空间谜题结合，经营和探索是同一套规则。
- 《路边的藤井》《妹妹知道》用亲友／同事视角发现一个普通中年人的生活方式或隐性才华。
- 《RIOT》把采访、摄影、排版、装订和发行组成 ZINE 制作循环，文化生产可成为地方青春冒险。
- 《魔女与佣兵》让两个奇幻世界原住民主动迁居未知大陆；“异世界”不等于现代人穿越。
- 实录漫画《“坛蜜”》补充伴侣观察、非同居婚姻和非虚构叙述者偏见。

核心变化：截至 2026 年中，显著样本越来越重视“世界事件之后谁来研究、维护、记录、出版、经营和照料”。

## 3. 应加入 HTML 的新标签轴

### 3.1 生命阶段

```text
儿童 / 少年 / 青年 / 壮年 / 中年 / 老年
职业起步 / 职业巅峰 / 退役 / 离职重启 / 丧偶后 / 育儿中 / 返校
```

年龄必须影响身体、制度资格、经济与关系，但不能用来过滤“不常见主角”。65 岁电影新生、中年退役杀手、老年修仙初学者都应是合法组合。

### 3.2 身体与存在形态

```text
人类 / 人外混血 / 动物 / 怪物 / 史莱姆 / 器物 / 幽灵
可变身体 / 双魂共生 / 被替代者 / 长寿种 / 人工生命
感官差异 / 神经多样性 / 身体与社会性别表现分离
```

身体不是装饰。选择“猫”应改变移动、沟通、被照料和法律身份；选择“史莱姆”应提供变形和材质特性，但不自动添加吞噬升级。

### 3.3 与世界的关系

```text
本地原住民 / 异地移民 / 现代穿越者 / 前现代穿越者
回归者 / 转生者 / 原作角色 / 原作路人 / 原人格
游戏玩家 / NPC / 测试员 / 旁观解说者 / 后日谈幸存者
```

“异世界”只是世界关系之一。玩家可以是两地奇幻原住民之间的移民，也可以从历史世界穿到奇幻，而非固定现代宅男。

### 3.4 叙事位置

```text
英雄 / 英雄的朋友 / 旧队友 / 后勤 / 导师 / 学徒 / 观察者
退役者 / 脱离组织者 / 普通员工 / 店主 / 房东 / 司书
保险调查员 / 怪兽学者 / 动物保护者 / 工匠 / 创作者
反派原人格 / 双魂继承者 / 边缘球员 / 群像中的一员
```

叙事位置必须独立于战斗职业。例如“仙侠 × 司书”“赛博 × 保险理赔员”“武侠 × 旧队友的遗孀”“异世界 × 动物保护者”都应可生成。

### 3.5 故事发动机

```text
职业案件 / 固定店铺接待 / 团队项目 / 制作与发行 / 技能训练
照料与救助 / 经营与维护 / 旅行与微旅行 / 调查与采样
关系重建 / 普通生活训练 / 后日谈 / 多周目重建
设施探索 / 公开竞赛 / 规则调试 / 社区协商
```

发动机决定事件池。选择“旧书店”时优先生成收书、估价、顾客、书籍去向与店务；不得每三回合自动出现神秘组织。

### 3.6 能力约束

```text
次数限制 / 条件触发 / 使用代价 / 社会禁忌 / 身体负荷
需要队友 / 需要材料 / 需要许可 / 只能解决局部问题
强度过高导致关系失衡 / 知识存在但操作不足
```

《感谢投球》的“三球限制”和《钻石的功罪》的“天赋外部性”都说明：能力越强，越需要清楚的选择成本。

### 3.7 关系结构

```text
挚友 / 旧友 / 兄妹 / 师徒互育 / 年龄差友谊 / 选定家人
女性双人事业 / 百合 / 无恋爱 / 多关系协商 / 人宠共同生活
原人格与转生者 / 护卫契约 / 创作搭档 / 队友竞争
难以命名的长期关系 / 重新认识的前恋人
```

关系应保存边界、承诺、共同项目和已知事实，而不是只存一个好感数值。

### 3.8 结构与时间

```text
主线开始前 / 经典桥段进行中 / 决战后 / 退役后 / 回归后
单元剧累积 / 轮换主角 / 多视角 / 短篇连作 / 跨时代变奏
单向保留记忆 / 双方失忆 / 事实保留但关系重置 / 作品中作品
```

## 4. 数据库如何真正影响 HTML

### 4.1 不直接把 68 部作品塞进系统提示词

数据库的作用是检索抽象机制。每局只应选 3—6 条与当前组合相关的 `narrative_features` 和 `why_included`，再去除作品名与角色名，生成“导演可供性”。

```text
玩家标签：老年 × 返校 × 创作项目 × 无恋爱
检索结果转译：允许经验与新手身份并存；每回合从选课、团队分工、器材、作品修改和同学关系中产生事件；年龄带来现实条件但不取消成长。
```

### 4.2 开局生成“前提契约”

```json
{
  "world": "仙侠城市",
  "embodiment": "退役灵剑的器灵",
  "life_stage": "存在三百年，但刚获得独立身体",
  "narrative_position": "勇者式剑修的旧友，而非本人",
  "story_engine": "修复旧法器与接待顾客",
  "relationship_core": "与已故持有者的孙女共同经营",
  "time_structure": "宗门大战结束后",
  "tone": "生活感70%，职业30%，悬疑10%",
  "power_constraint": "离开店内法阵后每天只能实体化三小时"
}
```

前提契约在开局后进入权威状态。模型不能在第三回合把器灵改成人类转生勇者，也不能无理由把修复店变成灭世阴谋入口。

### 4.3 使用事件池，不用“世界脉动 = 后台阴谋推进”

按故事发动机生成加权事件：

```text
职业事件 35%：新委托、材料短缺、错误诊断、同行协作
关系事件 25%：兑现承诺、共同休息、边界冲突、认识朋友
生活事件 20%：做饭、购物、天气、住房、身体状态
目标推进 15%：项目里程碑、考试、比赛、旅行节点
高压事件 5%：仅在已有因果与导演阶段允许时触发
```

不同模式可调比例，但“悬疑”不能通过普通世界脉动偷偷回到 50%。

### 4.4 每段文字必须有功能

针对用户指出的无关描述，生成后进行轻量校验：每个段落至少推进以下一项，否则压缩或删除。

```text
玩家行动结果 / NPC可观察行为 / 新的可用事实
关系变化 / 权威状态变化 / 感官上必要的场景定位
```

禁止为了“文艺感”连续写天气、目光、沉默、远处声音和不明预感，却不给玩家可行动信息。

### 4.5 标签决定记忆优先级

| 故事发动机 | 必存长期事实 |
|---|---|
| 固定店铺 | 顾客偏好、欠款、库存、营业规则、回访约定 |
| 创作项目 | 版本、分工、截止日、反馈、版权、未解决修改 |
| 挚友／旧友 | 共同经历、边界、旧承诺、互称方式、分歧原因 |
| 动物／照料 | 健康、饮食、习惯、医疗、照料人、安置状态 |
| 多周目恋爱 | 哪一方保留记忆、当前周目亲密度、已重新公开的信息 |
| 职业调查 | 证据来源、已验证事实、待检假设、权限和责任人 |
| 经营建设 | 资源、雇员、供应链、客户、设施和项目阶段 |

这样“标签研究”会真正改善长上下文，而不只影响第一段开场。

### 4.6 关系不能只存好感度

建议关系状态至少包含：

```json
{
  "trust": 42,
  "openness": 70,
  "shared_projects": ["轻音部夏季演出"],
  "promises": ["周五一起选曲"],
  "boundaries": ["不替她向老师解释诊断"],
  "known_facts": ["她需要书面步骤应对临时变化"],
  "unresolved_conflicts": ["是否邀请前队友加入"],
  "current_distance": "朋友／合作伙伴"
}
```

### 4.7 稀有组合只做软兼容评分

系统只拦截逻辑矛盾，不拦截市场少见：

- `赛博都市 × 老年人 × 社区护理机器人 × 职业单元剧`：高兼容。
- `乙女游戏 × 原作路人 × 反派的女性朋友 × 无恋爱／百合可发展`：高兼容。
- `仙侠 × 失去修为的前宗主 × 动物救助 × 宗门大战后`：高兼容。
- `武侠 × 器物生命 × 镖局后勤 × 挚友流`：高兼容。
- `魔法学校 × 双方均无魔力 × 研究项目 × 女性双主角`：高兼容。

“不常见”正是生成器应该保留的价值，不应被预设身份菜单过滤掉。

## 5. 与 2016—2020 首批合并后的主要结论

两批合计 127 部作品后，可看出近十年漫画侧的稳定趋势：

1. 异世界与奇幻的创新越来越多发生在叙事位置，而非更大的能力数值。
2. 非人主角从怪物升级扩展到器物、宠物、可变身体、混血、替身和社会制度问题。
3. “主线结束后”已是成熟开局：退役、回归、丧偶、离职、脱离组织、英雄死后都可重新开始。
4. 职业劳动是最稳定的长篇发动机之一：料理、医疗、保险、司书、调查、工匠、创作、出版、救助、研究、经营。
5. 女性关系从攻略对象扩展为事业伙伴、互育师徒、挚友、共生人格、家庭与多种百合路线。
6. 普通人和低压力作品并不缺剧情，它们依赖具体行动链，而不是靠模糊气氛填字数。
7. 好的悬疑通常有明确关系或职业核心、可验证事实和有限秘密预算；差的悬疑才会让全员话说一半。

## 6. 局限

- 漫画大赏偏向卷数较少且书店员愿意推荐的作品；下一部人气漫画大赏偏向网络动员与年轻连载，两者不能代表整个市场。
- 女性向条漫、BL、成人向、同人和小型网络平台仍然不足，需要单独补样。
- 部分作品在代表年份前已连载；本数据集不能用于首发年比较。
- `tags`、`protagonist_role` 与 `why_included` 是面向生成系统的分析编码，不是出版社官方分类。
- 2026 是截至 2026 年 7 月 11 日的年中快照，后续榜单和新作尚未发生。
- 小说改编只占本批少数，因为轻小说由并行的日本轻小说研究库负责更全面覆盖；这里优先保留“漫画化后仍展示特殊叙事机制”的案例。
