# LLM 互动叙事系统方法：项目导向的系统文献综述协议

**协议版本**：1.0  
**冻结日期**：2026-08-21  
**用途**：为 `my-rpg` 的下一轮架构决策建立可追溯证据，不直接把单篇论文转成产品功能。  
**报告规范**：采用 PRISMA 2020 的检索、筛选和报告结构；由于对象是异质的计算机系统研究，不预设统计合并，优先采用结构化叙述综合。  
**注册状态**：未注册。本综述用于项目决策而非投稿；若后续用于学术发表，应在正式检索重跑前注册 OSF 协议。

## 1. 研究问题

### 主问题

在开放式、连续多回合的 LLM 互动小说或文字 RPG 中，哪些系统方法能够改善以下结果，并且这些改善由什么级别的证据支持：

1. 长程情节与因果一致性；
2. 角色人格、知识边界和关系连续性；
3. 玩家能动性与可理解的选择；
4. 记忆、世界状态和事实一致性；
5. 局部场景质量、节奏和文本相关性；
6. 延迟、token、模型调用数和实现复杂度。

### 次问题

- 规划、反思/修订、多 Agent、检索记忆、符号状态和约束解码分别解决什么问题，不能解决什么问题？
- 哪些论文只在离线故事生成上有效，哪些证据能够外推到玩家逐回合介入的互动叙事？
- 评价指标是否真的测到了“好玩”和“连续可玩”，还是只测短文本偏好、角色问答或自动分数？
- 对单人本地项目而言，哪些方法的质量收益足以抵偿额外等待和 API 成本？

## 2. 范围框架（PICOS 的软件系统改写）

| 项目 | 预先定义 |
|---|---|
| Population / 场景 | LLM 驱动的互动叙事、文字 RPG、角色扮演、长篇故事生成，或能直接支持这些系统的长期角色/记忆研究 |
| Intervention / 方法 | 层次规划、剧情导演、反思与修订、多 Agent 协作、角色建模、检索记忆、结构化状态、神经符号约束、时间/知识边界控制 |
| Comparator | 基础单模型续写、无规划/无记忆/无反思的消融、其他系统方法，或同一研究内的人工偏好对照 |
| Outcomes | 一致性、相关性、角色忠实、能动性、沉浸感、故事质量、错误率、成功率、延迟、token/调用成本 |
| Study designs | 同行评审论文优先；包含具有完整方法与实证评估的高相关预印本；概念稿仅作背景，不作为实现依据 |

## 3. 纳入与排除标准

### 纳入

1. 2018-01-01 至 2026-08-21 公开的论文；2018 年前只纳入被后续方法反复依赖的奠基工作，并单列为背景。
2. 英文或中文全文可获取；日文研究若有足够英文方法与结果信息也可纳入。
3. 至少满足一个直接条件：
   - 生成或管理互动故事/互动戏剧/文字冒险；
   - 生成长篇、多场景故事并评估长程一致性；
   - 评估或改善持续角色扮演中的人格、知识或记忆一致性；
   - 提供可直接用于叙事系统的记忆/状态方法，并包含相关任务评估。
4. 对核心结论提供可检查的方法、比较或结果。

### 排除

1. 只讨论普通聊天 Agent、通用 RAG 或工作流编排，未连接叙事、角色扮演或长程生成结果。
2. 只生成单段提示、短故事或静态角色简介，没有连续性问题。
3. 产品宣传、新闻、博客、代码仓库说明，没有可审查实验；可用于定位论文，不能作为结论证据。
4. 只有摘要且无法取得足够方法和结果。
5. 重复报告同一系统时，保留信息最完整版本，其他版本只作关联记录。
6. 研究仅评价模型知识问答或通用推理，不能合理外推到互动叙事。

## 4. 信息源与检索计划

### 核心来源

1. ACL Anthology：NLP、故事生成、角色扮演、评价；
2. ACM Digital Library：互动叙事、HCI、智能角色与游戏；
3. IEEE Xplore：游戏 AI、交互系统与计算智能；
4. arXiv：捕获 2025-2026 尚未完成同行评审但与项目直接相关的新方法；
5. Semantic Scholar / Google Scholar：仅用于发现、前向/后向引文追踪，结论必须回到论文原文或出版社页面核验。

### 检索块

完整查询会在结果报告附录中逐条记录。核心布尔块预先固定为：

```text
("large language model" OR LLM OR "neural language model")
AND
("interactive narrative" OR "interactive storytelling" OR "interactive fiction"
 OR "story generation" OR "long-form story" OR role-play* OR persona OR character)
AND
(planning OR outline OR coherence OR consistency OR memory OR retrieval
 OR reflection OR revision OR "multi-agent" OR director OR drama OR agency
 OR controllability OR evaluation)
```

为防止一个超长查询漏检，正式搜索拆成五组：

- S1：长篇故事 + planning / outline / revision / coherence；
- S2：interactive narrative / drama + agency / director / plot management；
- S3：role-playing / character + persona / knowledge boundary / consistency；
- S4：narrative + memory / retrieval / state / neuro-symbolic；
- S5：story / role-play + benchmark / evaluation / metric / human evaluation。

## 5. 筛选与记录

1. 保存每个来源、查询、日期、命中数和可导出的元数据。
2. DOI、正式论文 URL 和规范化标题用于去重。
3. 第一轮按标题/摘要筛选；第二轮阅读全文。
4. 每篇全文排除项记录唯一主要理由。
5. 单人项目审阅的限制明确标注；对最终 A 级结论进行第二次独立复核式重读，但不虚构“双审”。
6. 输出 PRISMA 风格流程计数：识别、去重、初筛、全文、排除原因、最终纳入。

## 6. 数据提取字段

| 类别 | 字段 |
|---|---|
| 文献 | 标题、作者、年份、venue、DOI/URL、同行评审状态 |
| 问题 | 目标缺陷、使用场景、互动还是离线、生成跨度 |
| 方法 | 模块、调用顺序、状态表示、模型职责、是否需要训练 |
| 比较 | baseline、消融、比较模型、人工/自动评价设计 |
| 结果 | 样本量、指标、效应方向、可提取的数值、不确定性 |
| 工程 | 每回合调用数、额外上下文、延迟/成本报告、代码/数据可得性 |
| 局限 | 任务替代性、模型依赖、评估偏差、可复现性、对本项目的间接性 |
| 项目映射 | 对应现有模块、预期收益、失败模式、最小可证伪实验；此栏在综合完成后填写 |

## 7. 质量与偏倚评估

医学干预用的 RoB 2 / ROBINS-I 不适合直接套到生成系统论文。本综述预先采用六域计算机系统研究量表，每域 0-2 分：

1. 方法与运行链路是否足够清楚；
2. 是否有合理 baseline 或关键消融；
3. 人工评价的样本、盲法/随机化和一致性是否报告；
4. 指标是否有效对应所声称的叙事结果；
5. 是否跨模型、数据或场景验证；
6. 代码、数据、提示词或复现细节是否可得。

总分不替代判断；同时单独标注：选择性报告风险、作者自评风险、LLM-as-judge 循环偏差、短任务外推风险和预印本状态。

### 项目证据等级

- **[A] 直接且较强**：同行评审；任务直接相关；有清晰比较/消融；包含可信人工或行为评价；结论与结果匹配。
- **[B] 有条件支持**：方法相关但任务间接，或仅自动评价/单一模型/较小样本；也包括设计完整、评估充分但尚未同行评审的新预印本。
- **[C] 探索性**：概念系统、演示、扩展摘要、弱比较，或只能提供设计灵感。

## 8. 综合方案

- 预计方法、任务和指标高度异质，不预设 meta-analysis。
- 采用 SWiM 风格的结构化叙述综合，按五条问题链分别汇总支持、反例和边界。
- 不以“论文数量投票”替代证据强度；同一研究团队、同一基准和同一模型族的结果需标记依赖。
- 单独建立“效果证据”和“工程代价”两张矩阵，避免质量收益与复杂度混为一谈。
- 只有至少一项 [A] 或两项相互独立的 [B] 证据，并且存在适合本项目的可证伪验收，才进入推荐架构；否则只进入实验候选。

## 9. 预先定义的项目决策门槛

研究结束前不修改运行架构。综合完成后，每项候选方法必须回答：

1. 它针对的是哪个已观察故障，而不是泛泛的“更智能”？
2. 现有系统是否已经部分具备，避免重复增加 Agent？
3. 最少增加多少调用、等待和 token？
4. 失败时是否能安全回退，不丢正文、不损坏存档？
5. 用什么固定测试集证明比当前版本好？
6. 是否会损害既有验收项：世界观、模型供应商、主界面/存档、长文本、SSE、回车发送和行动选项？

## 10. 协议偏差与局限

- 当前由单一项目审阅者执行，无法声称真正的双人独立筛选。
- 部分付费数据库只能检索元数据或摘要；全文不可得时不得给 A 级结论。
- 2026 年论文仍可能处于预印本或刚发表状态，必须与成熟同行评审证据分层。
- 这是工程决策综述，不把“论文中显著”直接等同于“在本项目中有效”；最终必须通过固定存档与相同输入的对照实验。
