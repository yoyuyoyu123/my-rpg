# 中国网文样本库（2016—2020）研究说明

## 1. 范围与口径

- 数据文件：`china_works_2016_2020.json`
- 样本规模：53 部；2016 年 10 部、2017 年 11 部、2018 年 10 部、2019 年 11 部、2020 年 11 部。
- 地区字段统一为 `CN`，字段顺序与 `china_works_2021_2024.json` 对齐：`region / year / title / author / platform / popularity_basis / tags / protagonist_role / narrative_features / why_included / sources`。
- `year` 表示作品在该年度的连载、完结、榜单入选或类型影响力的代表年份，不一定等于首次发布年份。长篇网文跨年连载很普遍，因此同一作品可能在后一年蓝皮书中被回顾或确认影响力。
- 选样不只看商业热度，也保留了对游戏生成有价值的特殊叙事角度，例如：非人主角、NPC 视角、基层官吏、父女/亲子、幕后辅助者、封闭空间、职业技术流、反向系统和时间循环。

## 2. 研究方法与证据层级

1. 以中国作家网、中国作协网络文学年度榜、网络文学蓝皮书和《文艺报》年度类型观察为主干，建立每年题材与代表作品候选池。
2. 用起点中文网、晋江文学城、书旗、番茄等作品页或荣誉页核对作者、平台、文案、连载时间、站内荣誉和原生标签。
3. 对改编影响、跨年传播和类型史地位，用中国作家网后续评论或年度报告交叉确认。
4. 标签采用“可组合生成维度”，不照搬平台单一分类。每部作品同时描述世界/时代、主角身份、叙事机制、关系结构、基调与结构特色。
5. 只有来源能支持的事实才写入 `popularity_basis`；`tags` 和 `narrative_features` 是对作品文本机制的研究性归纳，不代表平台官方标签原文。

来源优先级：

- 一级：国家级/行业权威年度榜单、蓝皮书、作品原始连载页或官方荣誉页。
- 二级：权威媒体评论、平台专题页、改编官方资料。
- 辅助：在官方页面缺失时用于确认传播或改编的资料；本批仅少量使用。

## 3. 年度趋势摘要

### 2016：IP 高潮下的类型扩张与“职业/生活”入口

2016 年样本已经不是单一玄幻升级线。现代言情开始把程序员、创业和人物共同成长写进关系叙事；历史文从帝王将相转向乱世草根与历史可能性；现实职业文以相声、师徒和行业生态为主轴；科幻出现生物朋克、基因伦理和未来学院。仙侠内部同时出现宗门生活喜剧、网络聊天群式都市修真，异世界文则把工程、工业化、领地治理和群像协作变成剧情发动机。女性向重生文突出“身份既有约束 + 主体重新选择”，刑侦文则把案件、社会问题和创伤修复并置。

可抽取的生成轴：`职业专精 / 生活流仙侠 / 网络社群修真 / 工业建设 / 历史小人物 / 女性重生改命 / 社会派刑侦 / 生物朋克`。

### 2017：专业现实、温情日常与女性向类型升级

工业制造、国企技术和团队事业构成现实题材的重要方向；“奶爸 + 文娱 + 美食 + 亲子”的低压力生活流证明主线不必依赖阴谋。时空交错可以服务民国与现代职业人物的相遇，而不必直接等同于宏大救世。东方玄幻强化中国神话、文明史与另类师徒；仙侠出现转世重修与哲思慢热。女性向作品把星际革命、机甲、刑侦缉毒、数学教育、父女关系、现代武术和职业坚守纳入主流，主角可以是法医、律师、警察、数学学习者、失势神官或废弃星系中的普通人。

可抽取的生成轴：`工业事业 / 奶爸亲子 / 跨时空相遇 / 失势神官 / 数学教育 / 女性职业成长 / 星际底层革命 / 现代国术`。

### 2018：垂直专业化、规则副本与跨类型体系设计

这一年代表作品显著强调“细分类型做到极致”。蒸汽朋克、克苏鲁、序列成长和多身份社群被组织成完整体系；都市异能借灵气复苏、负面情绪、超能猫和家庭/萌宠喜剧降低传统玄幻的沉重感。科研、数学、外科手术、医院群像成为可持续的职业任务链。恐怖题材出现“鬼屋经营 + 员工群像 + 单元怪谈”，无限流则发展出门、考试、规则、闯关和反系统等不同入口。国术、民俗神怪、星际修真、炼器与文明政治的交叉，说明世界观标签应可自由组合。

可抽取的生成轴：`序列体系 / 灵气复苏喜剧 / 科研升级 / 医疗职业任务 / 恐怖经营 / 民俗无限 / 考试副本 / 科幻修真`。

### 2019：反套路身份、历史制度感与女性穿书/重生分化

仙侠从“勇者本人”继续向谨慎幕后辅助者、盲眼游历者、被误认为高人的普通行动者扩展；“稳健流/苟道”把风险管理本身变成爽点。历史穿越强调基层官吏、律法、军功、南宋制度与群臣协作，身份不只限于皇帝或名将。游戏异界出现 NPC 主角面对玩家降临的元叙事；现代奇幻可以由机构、灾厄、乐师、黑色幽默和理想主义共同驱动。女性向穿书把系统任务、原作人物关系和反派攻略结合，重生文强调对前世权力与关系的重新选择；星际军校文则以贫困女学生、机甲竞赛和团队群像替代娇宠路线。时间循环证明有限场景与普通人救援也能支撑高强度故事。

可抽取的生成轴：`稳健幕后流 / 高人误会 / 基层制度史 / NPC 视角 / 机构异常 / 原作反派攻略 / 女生军校机甲 / 时间循环救援`。

### 2020：类型融合、免费阅读爆发与“非标准主角”普及

废土不再只有孤狼求生，也容纳流民、聚居地、特殊家庭、机构调查与群像成长。高武把学院、文明师、万族和诸天战场组合成高速升级结构；古代探案把衙门职业、仙侠体系、朝堂与轻喜剧融合。系统文进一步出现“必须亏钱”的反向目标，通过公司经营、误解流和员工群像制造冲突。女性向现代言情强调重逢、合租、暗恋与创伤修复；末日科幻出现蘑菇等真正非人主角，让身体、感知、伦理归属和物种存续参与叙事。无限流加入直播、团队、欲望和资本隐喻。免费阅读平台则放大草根生计、地摊、都市异能、密集笑点和快速反馈的爽文结构。

可抽取的生成轴：`聚居地废土 / 古代职业探案 / 反向系统经营 / 精神污染调查 / 非人物种主角 / 直播无限 / 草根摆摊 / 都市创伤修复`。

## 4. 对 HTML 小说游戏数据库的直接用法

不要把作品名直接塞进提示词让模型模仿；应将本库转成可正交组合的标签与机制库。推荐至少拆成以下维度：

- 世界与时代：现代、古代、民国、近未来、星际、末日、异世界、架空历史、都市超凡。
- 存在形态：人类、非人、动物、植物/菌类、器物、AI、鬼怪、神官、分身、群体意识。
- 社会身份：基层官吏、职业医生、学生、工人、创业者、掌柜、军校生、NPC、幕后辅助者、勇者挚友、失势贵族。
- 来历机制：原生、重生、穿越、穿书、转生、时间循环、记忆继承、玩家降临、误入聊天群。
- 剧情发动机：职业任务、经营建设、考试副本、案件调查、关系修复、旅行见闻、竞赛、制度改革、求生、科研、日常生计。
- 关系结构：亲子、师徒、兄妹、搭档、团队、宿敌、前队友、挚友、群像社区、跨时空伴侣。
- 叙事位置：主英雄、辅助者、观察者、失败者、退队者、反派阵营、原作配角、被召唤者、普通市民。
- 结构与基调：单元剧、章节长线、有限场景、群像、多身份、轻喜剧、治愈、热血、正剧、低压生活、悬疑。

生成规则建议：

1. 用户未选择的标签不能自动激活，尤其不能把“穿越、系统、非人、乙女/百合游戏、仙侠、赛博”自动绑定成固定套餐。
2. “系统”只是约束机制，不应代替主角欲望、职业任务和人际关系。
3. 选择非人主角时，必须在身体能力、感知方式、交流障碍、社会处境和伦理归属中至少落实两项，不能只换皮。
4. 选择职业身份时，剧情必须提供真实可执行的职业任务链，而非只把职业写进背景。
5. 悬疑、阴谋、幕后组织是可选风格标签，不是世界默认状态；低悬疑时信息应通过正常对话、公开规则和可验证行动获得。
6. “主角位置”与“世界类型”分离：仙侠也可做店铺经营、巡山杂役或师兄辅助；赛博也可做社区维修、虚拟偶像运营或公司审计；武侠也可做镖局账房、退队旧友或地方捕快。
7. 先由程序抽取 6—10 个互不冲突的标签，再把对应机制和约束注入提示词；不要把全部 53 部作品的描述一次性送入模型。

## 5. 局限

- 年度蓝皮书与国家级榜单有编辑、价值导向和平台覆盖偏差，可能低估免费阅读平台、女性向站内爆款或已下架作品。
- 平台作品页能证明作品信息和站内表现，但不能单独代表全市场热度；因此数据库将“权威年度入选”“平台荣誉”“类型影响/改编传播”分别写入 `popularity_basis`。
- 长篇作品跨年连载，年度归类是为趋势研究服务，不可用于精确断言首发年份。
- 标签是面向叙事生成的研究归纳，不是版权方或平台的官方完整标签。
- 本文件是第一批 2016—2020 样本；与 2021—2024、日本轻小说及漫画样本合并后，仍需做标签去重、同义词规范化和冲突规则测试。

## 7. AI 辅助研究披露

本数据库由 AI 辅助进行候选池整理、标签归纳、字段标准化和交叉核验。作品与榜单事实尽量回溯到上述权威年度资料或原始平台页面；标签和“为何纳入”属于研究性归纳，使用前仍应按产品目标进行人工抽样复核。
