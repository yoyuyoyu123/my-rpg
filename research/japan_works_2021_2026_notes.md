## 3. 年份口径与局限

1. `year` 表示作品在本研究所采用的年度榜单、奖项结果或市场观察节点，不保证等于最早 Web 连载年、首卷出版年或动画化年份。
2. 2026 年只有截至 2026-07-12 可见的比赛结果与动态榜，因此必须称为 `2026 YTD`，不能与完整年度直接比较。
3. 2025—2026 的长期销量、动画带动与最终榜单还会变化；本批更适合捕捉标签和机制，而非预测最终商业冠军。
4. 标题很长的 Web 小说保留主要正式标题，个别出版社副标题版本可能存在标点差异。
5. 作品简介被压缩为原创中文归纳，没有复制长篇官方文案；需要用于公开文章时应再次核对出版社书目页。

## 4. 2021—2026 的主要类型变化

### 2021：身份反转从开局噱头变成长期角色系统

2021 样本仍有恶役令嬢、乙女游戏和异世界，但已经明显分叉：

- 《ループ7回目の悪役令嬢》把每次人生的职业经验做成能力库，恶役身份只是入口。
- 《歴史に残る悪女になるぞ》让女主主动追求“恶女”目标，而非只求洗白。
- 《負けヒロインが多すぎる！》把传统恋爱故事的失败者和配角移到中心。
- 《俺は星間国家の悪徳領主！》将误解系、领地经营和太空歌剧组合。
- 《ギルドの受付嬢ですが》把公会柜台、文书和加班变成冒险动机。
- 《VTuberなんだが配信切り忘れたら伝説になってた》说明直播人设、弹幕和事故已经成为独立叙事形式。

对游戏提示词的意义：不要把“恶役令嬢”写成一条固定逃婚路线；它应拆成对原作的态度、掌握的职业经验、与既定角色的关系、是否愿意承担政治责任等多个可组合轴。

### 2022：职业、身体差异和社会规则开始压过单纯外挂

- 《貞操逆転世界の童貞辺境領主騎士》把性别规范反转扩展到婚姻、继承、军役和名誉。
- 《第七魔王子ジルバギアス》让前勇者转生为敌方魔族王子，亲情和复仇持续冲突。
- 《服飾師ルチアはあきらめない》以服装设计、工坊、订单和品牌作为主循环。
- 《サイレント・ウィッチ》让社交恐惧既是能力来源，也是任务限制。
- 《人外教室の人間嫌い教師》把人外少女写成学生与文化主体，而非怪物素材。
- 《魔術師クノンは見えている》将盲人感知和实验研究变成魔法成长逻辑。
- 《恋した人は、妹の代わりに死んでくれと言った。》从被替代、被牺牲的女性余生开始，而不是从英雄救援开始。

对游戏提示词的意义：身份生成必须允许“服装师、教师、研究者、卫生员、守门人、工坊主”等非战斗职业；身体差异应改变信息获取和行动方式，不能只是一句外貌标签。

### 2023：配角、记录体、职业化极端事件与小规模怪谈

- 《魔王と勇者の戦いの裏で》是“勇者朋友而非勇者本人”的典型：勇者外出时，朋友处理内政、守城和后勤。
- 《TS衛生兵さんの戦場日記》从基层卫生兵日记描写战争，不给医疗奇迹和英雄光环。
- 《誰が勇者を殺したか》用访谈和互相矛盾的证词重建勇者一生。
- 《死亡遊戯で飯を食う。》把死亡游戏变成重复职业，强调经验、麻木和长期创伤。
- 《週に一度クラスメイトを買う話》用固定金额、周频和命令规则构造百合关系实验。
- 《バスタブで暮らす》证明极低行动力与封闭空间仍可构成完整故事。
- 《みんなこわい話が大すき》代表地方性、单元化现代怪谈，不需要最后汇入灭世组织。
- 《庭にダンジョンができたと思ったら、レベル1のまま25年》把现代地下城写成错失热潮后的中年再起。

对游戏提示词的意义：可选择的主角位置应包括记录者、证人、后勤、失败者、幸存者和“错过时代的人”；同时允许日记、访谈、论坛、报告、弹幕等非普通正文形式。

### 2024：成年人、制度奇幻、维护职业和非转生世界重新扩张

- 《私の心はおじさんである》长期处理年龄心态与身体性别错位。
- 《バスタード・ソードマン》允许有实力的成年人不追求顶点，只经营普通冒险者生活。
- 《オルクセン王国史》以兽人国家、工业、铁路、军制和族群政治构建架空历史。
- 《剣と魔法と学歴社会》把奇幻阶层流动具体化为升学、资格和社会资本。
- 《魔法使いの引っ越し屋》以搬家、物流、空间和客户人生组成单元剧。
- 《こちら、終末停滞委員会。》把末日变成需要分级和处理的机构业务。
- 《バケモノのきみに告ぐ、》用追想录连接怪物少女、都市传奇与记忆。
- 《ふつおたはいりません！》以女性声优、广播搭档和普通听众来信展开职业百合。

对游戏提示词的意义：世界观不应只决定敌人皮肤。教育、官僚、物流、传媒、工业和职业资格都应成为可选择的制度层；也要保留正统架空历史、现代怪异和宇宙 SF，而非全部强行转生系统化。

### 2025：对类型模板的自我反思，与 BL／乙女／关系类型继续交叉

- 《異世界転生勧誘詐欺》把转生开局拆成招募话术、合同与利益链。
- 《転生程度で胸の穴は埋まらない》反驳“转生即可治愈旧人生”的重置幻想。
- 《異世界転生ダンジョンマスター 温泉ダンジョンを作る》把地下城改成温泉、设施、客流和服务业。
- 《崩壊世界の魔法杖職人》把末世与制作、修理和客户需求结合。
- 《妖精の物理学》《デルタとガンマの理学部ノート》显示实验、观测和大学研究也能成为轻小说核心。
- 《荒くれ竜が言うことを聞かない》把人外龙、军务和 BL 关系结合。
- 《乙女ゲームの世界にモブ転生したようですが、始まる前に王子がドロップアウトしました》让乙女游戏的王子在开局前退场，并把路人男性推到 BL 路线。
- 《捨てられ公爵夫人は、平穏な生活をお望みのようです》强调离婚／被弃之后的成年人生活重建，而非必然复仇打脸。

对游戏提示词的意义：玩家可以拒绝“系统赠送的正确人生”，也可以质疑转生中介、选择服务业地下城、成为同性恋爱路线的路人，或者让原攻略对象直接退出剧本。

### 2026 YTD：平台获奖作品继续向文档原生、边缘岗位和路线拒绝发展

这部分尚非完整年度结论，但比赛结果已出现清晰方向：

- 《骸欠血損する食品群に関する一連の報告書》以网站、报告、乱码和信息损坏构成伪纪录恐怖。
- 《双剣無頼》让现代地下城底层清扫工成为主角。
- 《学園SP》让前佣兵转生为 Galgame 路人和女主护卫，不争夺攻略对象身份。
- 《辺境伯貴族家の息子、魔道具修理で無双し王女をも救う》强调维修、故障诊断和地方职业。
- 《乙女ゲームでヒロインの幼馴染に転生しましたが、当の本人は攻略対象と全く恋愛してくれません》让原女主主动拒绝全套攻略路线，为女性友谊或百合留下空间。
- 《リッチは少女を弟子にした》采用不死巫妖的时间尺度和教师身份。
- 《追放された修道女の屋台革命》把退队／追放导向餐摊、小生意和社区，而非立即复仇。
- 《断罪される未来を知った母は、誰にも告げず家を出た》将乙女式断罪世界的中心身份换成母亲和照护者。

## 5. 建议用于数据库的标签维度

不要把下面内容合并成一个长长的“题材”字符串。每个维度应独立存储，允许多选、权重和互斥规则。

- 小说／漫画既知世界
- 现代世界异常化
- 架空历史
- 宇宙／未来 SF

### B. 主角在原剧情中的位置

- 天选英雄

- 反派／恶役令嬢／恶役令息
- 路人／幼驯染／护卫
- 失败女主／第二顺位对象

- 普通第三／第一人称
- 多视角
- 日记

- 论坛／弹幕／直播

### G. 压力与剧情口味

- 低压力生活
- 职业成长

## 6. 用于 AI 小说游戏的组合原则

### 6.1 不要让单个标签写死整局

错误做法：选择“乙女游戏”后，固定生成恶役令嬢、退婚、四名王子、死亡结局。

建议做法：分别抽取或由玩家选择：

1. 原世界媒介：乙女游戏。
2. 身份位置：女主幼驯染、王子护卫、已婚母亲、路人教师、攻略对象的兄长等。
3. 对原作态度：遵循、不了解、主动拒绝、剧情已崩坏、原女主拒绝攻略。
4. 关系倾向：友情、百合、BL、家庭、无恋爱、群像。
5. 职业循环：上学、经商、维修、警卫、研究、治理。
6. 压力等级：日常、轻冲突、调查、危机。

这样“乙女游戏”只是一个世界来源，不再是剧情判决书。

### 6.2 为每局设置身份许可而非身份限制

推荐字段：

```json
{
  "identity_permissions": {
    "allow_nonhuman": true,
    "allow_object_or_facility": true,
    "allow_supporting_role": true,
    "allow_adult_or_parent": true,
    "allow_gender_variance": true,
    "allow_route_refusal": true,
    "allow_no_romance": true,
    "allow_yuri": true,
    "allow_bl": true
  }
}
```

许可默认开放；只有玩家主动选择严格复刻某种类型时才关闭。

### 6.3 每个职业都要有可重复行动

职业不能只是人物简介。数据库应为职业保存 4 类动作：

- 核心劳动：修理、诊断、设计、治疗、搬运、授课、采访。
- 社交对象：客户、同事、上司、学生、竞争者、社区居民。
- 资源：材料、时间、信誉、客流、资格、情报。
- 常见后果：返工、口碑、疲劳、事故、关系改善、制度阻力。

这能让服装师、搬家工、卫生兵或广播主持的玩法像真正职业，而非等待模型强行塞入战斗。

### 6.4 非人身份要改变感知、需求和社会位置

异种标签不应只替换外貌。巫妖可能有不同时间尺度，龙有领地和驯养权力问题，妖精可能受观测影响，兽人国家有自己的制度，设施意识可能关心客流与维护。至少生成：

- 身体能力与限制
- 信息感知方式
- 食物／能量／维护需求
- 与人类制度的关系
- 生命周期与亲密关系难题

### 6.5 原作知识应有可靠度

乙女游戏、Galgame 和 RPG 转生作品越来越常见“原女主拒绝路线”“关键王子提前退出”“教程前行动改变资源”“原作知识版本不一致”。建议保存：

```json
{
  "canon_knowledge": {
    "source": "前世玩过的游戏",
    "coverage": 0.55,
    "reliability": 0.65,
    "route_drift": 0.40,
    "known_version": "本篇但未玩DLC"
  }
}
```

模型不得把玩家记忆当绝对预言；剧情偏航必须来自已经发生的选择，而非无解释地宣布世界有更大阴谋。

## 7. 数据库检索建议

为避免直接把 79 条作品全文塞进上下文，建议建立两个层级：

1. **作品层**：保留当前 JSON 每条记录，用于研究查看、出处追踪和灵感回溯。
