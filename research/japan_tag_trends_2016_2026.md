# 日本小说标签归一与趋势审计（2016—2026 YTD）

## 1. 审计范围

本次只使用日本 Web 小说／轻小说库，不混入漫画标签，以避免漫画表现形式对小说类型频率造成偏移：

- `japan_works_2016_2020.json`
- `japan_works_2021_2026.json`
- `tag_ontology.json`
- 归一结果：`japan_tag_crosswalk.json`

合计 145 部作品、1,121 次原始标签赋值、953 个不同原始标签。年度作品数为：

| 年份 | 作品数 |
|---|---:|
| 2016 | 12 |
| 2017 | 13 |
| 2018 | 12 |
| 2019 | 14 |
| 2020 | 15 |
| 2021 | 13 |
| 2022 | 13 |
| 2023 | 13 |
| 2024 | 15 |
| 2025 | 15 |
| 2026 YTD | 10 |

需要特别注意：这是为扩大题材与叙事机制覆盖而构建的研究样本，不是全市场销量样本。953 个不同标签中绝大多数只出现一次，说明原始标签有意保留了作品差异。因此下文的次数表示“本研究样本中被观察到的作品数”，不能直接解释为日本市场占有率。

## 2. Crosswalk 动作定义

| action | 条目数 | 含义 |
|---|---:|---|
| `existing` | 35 | 原始标签与 `tag_ontology.json` 完全一致。 |
| `alias` | 544 | 原始标签可以映射到一个或多个现有本体标签。映射可能跨越世界、职业、关系、叙事形式等不同轴。 |
| `new_candidate` | 142 | 现有本体无法无损承接，建议评审后新增。多个原始词可能指向同一个候选标签。 |
| `keep_raw` | 232 | 低频作品级细节、宣传短语、否定条件或传播元数据；保留检索价值，但不提升到本体。 |

动作边界：

- `existing` 与 `alias` 的 `canonical_tags` 必须全部已经存在于本体。
- `new_candidate` 的 `canonical_tags` 是候选名称，尚未写入本体，不能直接用于生产筛选。
- `keep_raw` 的 `canonical_tags` 必须为空。
- 归一不删除原始标签。推荐同时存储 `raw_tags` 与 `canonical_tags`。

## 3. 归一方法

1. 先进行完全相等匹配。
2. 再处理人工审核的高频别名，例如：
   - `乙女游戏转生` → `乙女游戏世界` + `原作角色转生`
   - `领地经营` → `领地建设` + `领地发展`
   - `VTuber` → `VTuber直播` + `主播UP主`
   - `双视角` → `多视角POV`
   - `异世界美食` → `异世界餐厅` + `美食制作`
3. 对组合词做多轴拆分。例如“地下城直播”同时产生 `地下城社会`、`主播UP主`、`直播弹幕`，而不是创建一个越来越长的组合标签。
4. 对现有本体缺失、但跨作品有稳定意义的概念标为 `new_candidate`。
5. 作品专属钩子与否定型标签保留为 `keep_raw`。

已特别审计否定词，避免出现反向误映射：

- `非异世界转生` 不映射到 `異世界転生`。
- `反治愈外挂` 不映射到 `温馨治愈` 或 `疗愈恢复`。
- `非人关系` 映射到 `人与非人关系`，不映射成非人叙述视角。

## 4. 分阶段趋势

统计方式：先将每部作品的原始标签转换为 canonical／candidate 标签，再在单部作品内去重，最后统计拥有该标签的作品数。

### 2016—2018：异世界入口仍强，但团队、职业与政治已经并行

样本 37 部。出现较多的归一标签：

| 标签 | 作品数 | 样本占比 |
|---|---:|---:|
| 轻松吐槽 | 7 | 18.9% |
| 政治权力 | 7 | 18.9% |
| 群像交叉线 | 6 | 16.2% |
| 团队成长 | 6 | 16.2% |
| 异世界转生 | 6 | 16.2% |
| 关系成长 | 5 | 13.5% |
| 现实职业 | 5 | 13.5% |
| 亲子家庭 | 4 | 10.8% |
| 日常占主导 | 4 | 10.8% |

观察：

- “异世界”并没有独占叙事发动机。同期已经出现餐馆、职业将棋、团队经营、国家政治、亲子与地方生活。
- 非人主角与反英雄身份在此阶段已有明确样本，但原始标签表达分散，如不死者、史莱姆、异种转生和魔王视角。
- 喜剧与政治可以同时存在；不能把轻松文风等同于没有制度层。

对游戏的意义：初始世界可以是异世界，但主线应从职业、队伍、家庭、店铺或政治中独立选择，不能自动绑定讨伐魔王。

观察：

- 校园恋爱成为高可见结构，但《败犬女主》《第二顺位关系》《义兄妹生活》等作品不断把传统恋爱中心拆成配角、边界与日常协商。
- VTuber、声优、创作者、乐队等娱乐职业开始把“公众人设／私人身份”做成长期故事发动机。
- 恶役令嬢、回归、政治联姻与星际领主并行，说明身份表演已经跨出单一乙女游戏。

对游戏的意义：校园只是空间，关系结构应另选。玩家可以是败犬角色、朋友、旁观者、义兄妹、创作者或主播，并可选择无恋爱、百合、BL、友情或复杂关系。

样本 41 部。出现较多的归一标签：

| 标签 | 作品数 | 样本占比 |
|---|---:|---:|
| 疗愈恢复 | 6 | 14.6% |
| 战争局势 | 6 | 14.6% |
| 关系成长 | 5 | 12.2% |
| 群像交叉线 | 5 | 12.2% |
| 佣兵军人 | 5 | 12.2% |
| 政治权力 | 5 | 12.2% |
| 亲子家庭 | 4 | 9.8% |
| 现代都市 | 4 | 9.8% |
| 游戏世界 | 4 | 9.8% |
| 挚友情 | 4 | 9.8% |

该阶段还有多个重要但频次分散的方向：卫生兵日记、访谈证词、死亡游戏职业化、盲人感知、服装师、搬家业、魔道具研究、学历社会、兽人国家和现代怪谈。

观察：

- 战争题材从英雄战功转向卫生兵、守城、后勤、制度与创伤。
- “治疗”不再等于魔法回复数值，而是社交障碍、牺牲后果、孤独和关系恢复。
- 档案、访谈、日记、弹幕、追想录等信息形式增多。
- 主角位置明显外移：勇者朋友、配角、记录者、卫生兵、失败者和错过热潮的中年人都能成为中心。

对游戏的意义：导演应分别生成“事件压力”和“信息形式”。高压力战争也可以信息透明；低压力日常也可以采用日记、广播或多视角。

## 5. 优先新增候选

以下次数按所有指向该候选的原始标签使用量合并，不等于独立作品数，但能反映本体缺口。

### P0：应优先补充的结构轴

#### 主角档案轴

| 候选 | 原始使用量 | 原因 |
|---|---:|---|
| 女性主角 | 11 | 当前本体无法显式记录主角性别，却又强调“不默认男性或女性”。 |
| 成年主角 | 5 | 成年职业、家庭与经济责任已是稳定方向。 |
| 男性主角 | 4 | 应与女性主角对称，不能从 BL 或后宫反推。 |
| 中年主角 | 3 | 中年经验和身体年龄错位具有独立玩法。 |
| 儿童主角 | 3 | 儿童行动权限、监护和成长周期明显不同。 |
| 非人主角 | 3 | 已有非人身体类型，但缺少“非人作为叙事中心”的明确位置。 |

建议新增 `protagonist_profile`，其中年龄、性别呈现、是否非人中心应独立多选；不要把它们塞进 `embodiment` 或 `relationship`。

现有 `职业搭档`、`婚姻契约`、`女性群像` 都太具体，无法覆盖非职业搭档、金钱／友情契约或双女主但未定义百合的关系。

## 6. 不应提升到本体的标签

典型 `keep_raw`：

- 具体时间钩子：`25年后`
- 作品级排序／包装：`第二可爱`、`最强朋友`
- 单元事件：`惚药委托`
- 命题式短语：`侦探已死`
- 高度具体意象：`自我增殖车站`、`无人机谎言`
- 连载／传播元数据：`Web连载钩子`、`跨媒体`
- 否定条件：`非异世界转生`、`反治愈外挂`

否定条件未来适合进入单独的 `exclusions` 或 `anti_tags`：

```json
{
  "canonical_tags": ["现代都市", "职业案件单元剧"],
  "anti_tags": ["异世界转生", "自动治愈"]
}
```

不要为了降低 `keep_raw` 数量而把否定词硬映射成相反的正向标签。

## 7. 对 HTML 游戏数据库的使用建议

### 7.1 存两层标签

```json
{
  "raw_tags": ["勇者朋友", "国内守城", "后勤政治"],
  "canonical_tags": ["勇者挚友", "战争经营", "政治权力"],
  "ontology_version": "1.0.0"
}
```

- 原始标签用于精准检索灵感和保留语义。
- canonical 标签用于筛选、组合和统计。
- 新候选只有进入下一版本本体后才能成为正式 canonical 标签。

### 7.2 每部作品内去重

一个原始词可能映射到多个轴，多个原始词也可能映射到同一 canonical 标签。注入提示词前必须去重，否则模型会误判某个主题被特别强调。

### 7.3 不把候选词直接当剧情指令

例如 `女性主角` 只说明主角性别呈现，不能自动带出乙女游戏、恋爱、恶役令嬢或男性攻略对象；`生活流` 不能自动禁止冲突；`现代怪谈` 不能自动生成幕后组织。

### 7.4 组合时按轴抽样

一次开局建议分别选择：

1. 世界框架 1—2 个。
2. 主角来历 0—1 个。
3. 身体与主角档案各 0—2 个。
4. 叙事位置 1 个。
5. 职业 1—2 个。
6. 关系核心 0—2 个。
7. 故事发动机 1—2 个。
8. 信息形式 0—1 个。
9. 基调与压力各 1 个。

同一轴内部避免互相覆盖，不同轴允许自由组合。这样可以生成“乙女游戏世界 + 原女主幼驯染 + 修理职业 + 百合开放 + 低压力生活流”，而不是只调用一整块写死的乙女游戏模板。

## 8. 校验结果

- `japan_tag_crosswalk.json` 可被 JSON 解析。
- 记录数 953，与日本小说库不同原始标签数一致。
- `frequency` 合计 1,121，与作品标签赋值总数一致。
- `raw_tag` 重复数 0。
- action 仅包含 `existing`、`alias`、`new_candidate`、`keep_raw`。
- `existing`／`alias` 所有 canonical 标签均存在于 `tag_ontology.json`。
- `keep_raw` 的 canonical 标签数组均为空。
- 每条记录均包含 `raw_tag`、`frequency`、`canonical_tags`、`action`、`rationale`。

结论：现有本体已经能承接大量世界、职业和发动机标签，但对主角人口属性、一般生活流、关系协商、创作媒介、现代怪谈以及原作路线拒绝支持不足。优先补齐这些“正交轴”，比继续增加作品专属长标签更能提高 HTML 游戏的自由度。
