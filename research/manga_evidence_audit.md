# 漫画研究库证据审计（2016—2026YTD）

## 结论

两份漫画 works 文件共 127 条记录，现已统一使用 `evidence_strength`，并全部评为 A：

| 文件 | 作品数 | A | B | C |
|---|---:|---:|---:|---:|
| `manga_works_2016_2020.json` | 59 | 59 | 0 | 0 |
| `manga_works_2021_2026.json` | 68 | 68 | 0 | 0 |
| 合计 | 127 | 127 | 0 | 0 |

两文件均已通过 `JSON.parse`，每条记录的 `evidence_strength` 均紧邻并位于 `sources` 之前；旧字段 `evidence_grade` 已全部移除。

## 评级规则

- **A**：至少有一个官方奖项、出版社、连载平台或作品官方网站，能够支持作品存在、作者／改编关系、代表年份或纳入依据中的核心事实。
- **B**：没有足够官方页面，但有作者官方账号、专业行业媒体、图书馆／ISBN书目或可靠编辑采访支持。
- **C**：主要依赖百科、商业书店聚合页、读者社区或二手报道；仅宜用于发现和待核验样本。

评级针对“证据来源强度”，不表示：

1. 作品在全市场的销量排名；
2. 研究样本能够代表所有漫画读者；
3. `tags` 与 `why_included` 是出版社官方分类；
4. 奖项入围等同文学质量的绝对判断。

## 来源覆盖

- 127 部作品共有 192 次来源引用、101 个不同 URL。
- 65 部作品有 1 个官方来源；62 部作品有 2 个及以上来源。
- 主要证据来自漫画大赏、下一部人气漫画大赏、文化厅媒体艺术祭，以及讲谈社、KADOKAWA、集英社、小学馆、Square Enix、一迅社、TO Books、Overlap 等官方页面。
- 漫画原创 102 部、小说／游戏等改编漫画 24 部、实录／非虚构漫画 1 部。

来源角色分工：

| 来源类型 | 主要支持内容 |
|---|---|
| 官方奖项／榜单 | 代表年份、入围／获奖、读者或评选可见度 |
| 出版社书目 | 作者、卷次、出版时间、官方梗概、原作／漫画分工 |
| 官方连载平台 | 首话设定、连载形态、网络漫画身份、作者署名 |
| 动画／原作官网 | 小说改编关系、原作标签、跨媒体来源 |

## 为什么本批没有 B／C

本库是为提示词与标签系统建立的精选样本，不追求把所有候选都强行收入。检索过程中发现但只能由百科或社区支持的条目未写入 works；冷门作品只有在能找到官方书目、连载页或奖项档案时才保留。因此最终 127 条均满足 A 级最低条件。

这不意味着未来新增记录也应自动评 A。新增作品必须按同一规则单独检查；若只有行业媒体可用，应标 B，不得因同系列或知名作者自动继承等级。

## 结构校验要求

每条漫画记录必须满足：

```text
evidence_strength ∈ {A, B, C}
sources 为非空 URL 数组
evidence_strength 位于 sources 之前
```

A 级记录还必须至少命中一个官方域名。可重复运行 `apply_manga_evidence_strength.js` 进行当前两文件的官方域名和字段顺序校验。

## 审计边界

- 年份是研究代表节点，不保证等于初次连载年。
- 奖项页可证明入围与可见度，但复杂剧情标签仍属于研究者编码。
- 出版社梗概可能具有营销倾向，因此只用来确认基础设定，不直接照抄为风格评价。
- 2026 为截至 2026 年 7 月的年中快照，后续需重新审计新榜单和新作。
