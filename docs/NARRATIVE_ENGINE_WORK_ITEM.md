# NE-01：可试玩的小说模式

目标：在既有完整游戏中，让人物动机、连续性、场景时间与中文表达共同参与生成；质量优先，保留传统模式用于同模型对照。尚不能宣称优于 SillyTavern，必须经过实际盲测。

**游戏约束（玩家最新要求）**：交互主体始终是现有 RPG：自由输入、NPC、检定、角色卡、背包、技能、任务、存读档与撤销。新引擎仅替换回合中的叙事生成环节；不得增加章节创作、大纲编辑、自动写整章等写作工具流程。每回合仍响应一个玩家行动，在下一次选择前停下，提供现有行动按钮。

## 输入与输出合同

输入：既有编译提示词、玩家最新输入、场景卡、权威状态、有限原文记忆、显式写法偏好。模型只能提出候选；本地程序检查证据引用、图结构、预算并排名。未来节点均为假设，不能成为事实、知识或数值。玩家的新决定不属于推演权限。

输出：一篇通过校读的正文、汇总 token、带版本的运行信息与诊断。正文仍经过现有主权守卫、选项修复、状态审计和原子回合提交。运行信息与存档、撤销一起变化；生成端点不写数据库。前端以最终修订正文保存原文片段。

## 实现与数学假设

1. 有证据约束的事件 DAG + NPC 意图/感知证据；未知角色不能驱动候选，NPC 感知引用须来自该人物的明确知识。引文匹配只是来源检查，不等于语义证明；信息不足时回到已有场景。
2. 宽度 3、深度 3、折扣 0.65 的滚动束搜索；只执行首节点。它不是完整 MCTS/POMDP。
3. 场景已持续回合数与预计时长进入控制；允许继续、细写、概述和停顿，不设每回合冲突配额。是半马尔可夫时长思想的工程近似，不是学习完成的 SMDP。
4. 信息揭示计划与角色感知证据分开，交给校读检查泄密；没有把读者心理当作实测概率。
5. 质量模式两种写法、均衡模式一种；先排除校读指出的事实/主权/知识违规，再取质量维度的 Pareto 前沿并按显式偏好排序。必要时一次定向改写，改写须重新校读。
6. 原文片段采用中文二元字符相关性与 MMR，在字符预算中检索；权威事实仍使用既有 SQLite 记忆库。原文缓存有容量上限，不承诺永久全量召回。
7. 三种写法的 Beta 后验由玩家明确喜欢/不喜欢更新；探索奖励保留其他写法。没有用停留时间或模型自评分充当玩家奖励。
8. 可主动导出本机显式反馈和最近回合诊断，供离线评估；不含密钥与完整对话，不自动上传。本次不提供训练对导出，不声称完成 DPO/SFT 训练。

## 降级与边界

规划失败 → 使用既有场景与授权输入；部分写手失败 → 使用其他完成候选；全部写手失败/截断 → 本回合失败、恢复快照。校读不可用 → 显示降级提示，保留既有主权与状态守卫；校读明确判定全部违规 → 拒绝提交，不绕过。改写失败或复检不通过 → 保留已通过的原稿。

新模式先完整候选比较，再逐字显示选中正文；等待期间 SSE 阶段消息与心跳可见。每轮最多 1 规划 + 2 写手 + 1 校读 + 1 改写 + 1 复检（不含既有场景规划/裁定/状态审计及供应商重试）。设置明确标注额外时间和调用成本。请求有总时限，断开取消任务。传统模式完全保留。

## 固定验收与效果假设

固定场景：安静茶馆、不知情 NPC、玩家拒绝、已授权穿越、旧伏笔召回、候选泄漏、校读失败、全部截断、撤销/重载、提交失败。测试覆盖图的悬空节点/循环、预算、显式反馈与保存原子性。

H1：原文召回比仅摘要更能保留人物口吻。H2：多写法选择改善文笔但可能过度趋同。H3：前瞻改善因果，但不能夺取玩家决定。H4：持续场景降低回合切碎感。H5：明确反馈带来个人偏好适应。每项都需同模型、同开局、交换顺序、隐藏模式标签的配对试玩；主指标为玩家选择与问题标签，同时记录耗时/token。代码检查不能证明这些假设成立。

## 验证记录

基线安装发现 SQLAlchemy 2.1 异步依赖未声明，已改为 sqlalchemy[asyncio]。基线还有两项规则注册表失败：结构化写手的输出信封格式句被误归为状态裁定权；重写了该格式句，保留原意并通过原有断言，没有放宽基线。

自动验证（固定模型响应不代表真实文笔效果）：

- 后端完整测试：473 passed，3 xfailed（既有预期失败）；其中新增叙事引擎 26 项。
- 前端契约：全部通过；快照增加新运行信息的脱离引用检查。
- 既有确定性回放：10/10。
- 浏览器：主页、移动端、原 SSE 分帧/断流、原事务存读档/撤销、测试隔离均通过。
- 新浏览器游戏回归：真实叙事端点和本地算法、固定模型输出；自由输入与行动按钮、NPC/任务保留、程序骰子、背包/技能结算、原子存档、显式反馈、重载、撤销、提交失败恢复均通过。GM/状态审计模型答案固定，程序规则与数据库提交真实执行。测试服务默认阻止旧、新模型入口的实际付费调用。
- 反馈保存串行执行，防止与下一回合或撤销竞争；撤销等待自动保存完成。
- 测试环境使用已安装的 Chromium Headless Shell 141；可通过 RPG_TEST_BROWSER_EXECUTABLE 指定路径。外部字体在浏览器测试中使用空样式响应，避免网络错误干扰；移动端等候异步存档列表就绪后断言。

尚未验证：付费模型真实端到端生成、真人对文笔和人物感的偏好、长期数百回合表现、Windows 实机启动（启动器契约测试通过）。因此尚不能宣称胜过其他产品。

回滚：设置选“传统单稿”，或回到本分支之前的提交；新增存档字段可选，旧存档可直接加载。
