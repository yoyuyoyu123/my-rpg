# WEB-01：手机优先的私人在线游戏

目标：保留完整 FastAPI/SQLite RPG，通过一个 HTTPS 网站直接在手机玩，支持添加到主屏幕；GitHub 更新可自动部署。网站与 APK 并存，网页版仍需联网调用 AI。

部署选择：按玩家的新成本要求，优先支持 Fly.io 按需启停（东京、512 MB 运行内存、1 GB 购买单位的卷），闲置后停机并保留数据。Render 原生 Python 作为较简单的备选（7 美元/月实例 + 0.25 美元/GB/月磁盘）。均先用平台 HTTPS 域名，无需购买域名；AI 费用另计。单实例、单进程，避免 SQLite/单机存档的多副本冲突。持久化磁盘保留 SQLite、配置和签名密钥；重新部署可能短暂中断连接，正在生成的回合沿用失败回滚。Fly 仍有闲置根镜像和卷费用，不能称为免费。

权限：先做个人站，所有游戏 API/正文/存档/配置受登录保护；不是多人共享存档站。HTTPS、HttpOnly/SameSite Cookie、来源检查、失败次数限制。云端只允许已登录站主修改模型配置；桌面本机配置限制保持原样。没有密码时拒绝启动已启用保护的站点，不能把裸接口发布到公网。登录密码和 API Key 不写入 Git。实际付费部署需用户连接自己的托管账户并确认平台计费。

更新：HTML 与 API 不经 Service Worker 缓存。只缓存公开图标与离线提示页，不缓存存档、密钥或响应。网页检测版本更新，只在用户完成当前回合、完成存档后更新；不强制刷新游玩中的页面。离线不伪装 AI 可继续生成。

交付：PWA manifest/图标/离线与更新流程、私人登录、生产依赖、启动脚本、Render Blueprint、一键部署链接、Docker 备选配置与验证。平台账户未连接时不声称已上线，不创建付费实例。

追加范围：Google Gemini 官方兼容端点、OpenAI GPT-6 Luna 官方端点、独立 Key/预算字段/采样兼容与可选模型 ID。Luna 暂按 GPT-6 Luna 解释；不把没有真实 Key 的参数检查称为已验证模型效果。

固定验收：未登录/伪造 Cookie/跨站写入拒绝；登录后游戏与配置可用；持久化数据跨重启；会话退出；PWA 更新不打断回合、保存失败不刷新；全套原游戏回归；安卓构建保持兼容。

验证：生产与安卓两套 Python 依赖下后端均为 487 通过、3 个已知 xfail；手机尺寸浏览器验证私人登录、两个新 Key 保存与脱敏、模型列表、存档前更新保护、保存失败不刷新、成功保存后刷新、退出；原有小说模式完整回合回归通过。GitHub Actions [41327881081](https://github.com/yoyuyoyu123/my-rpg/actions/runs/41327881081) 已通过生产依赖、后端、浏览器、Docker 构建及真实容器卷重启验收：非 root 进程、SQLite 存档、私有 Key 配置、登录会话在重启后保留，退出后访问被拒。首轮验收脚本沿用旧的 Docker 临时端口，修正为重启后重读端口再通过。尚未使用真实 Key 调用两家模型，也未开通托管服务。
